## 🚀 Projeto em destaque

**[Arena Dolla — Sistema de Replays](https://github.com/almeidadevml/arenadolla-backend)**

Sistema de replays para uma arena de futevôlei: uma câmera grava o jogo o tempo todo, e com um clique os últimos 30 segundos viram um replay, que é enviado automaticamente para uma API na nuvem.

- [Serviço de captura](https://github.com/almeidadevml/arenadolla-capture): buffer contínuo com ffmpeg e botão de replay
- [API](https://github.com/almeidadevml/arenadolla-backend): Python com FastAPI, publicada no Render
- Banco de dados PostgreSQL e vídeos guardados no Supabase
